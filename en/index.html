Homelab · 2026

asushome1

An old laptop turned into a server at home, running my projects online, including this portfolio. I designed it to be reachable from the Internet without exposing anything of my home network.

Hardware

Machine
2017 ASUS X541UA laptop, running lid closed, headless
Processor
Intel Core i5-7200U, 2 cores and 4 threads
Memory
8 GB of RAM, 500 GB SSD
Network
100 Mbit/s Ethernet
Power
The battery acts as a UPS, with a clean shutdown during long power cuts

How it is exposed

  • No open port on the home router: websites go through a Cloudflare tunnel, an outbound connection from the server to Cloudflare
  • Cloudflare runs the domain's DNS, with DNSSEC, enforced HTTPS, attack protection and caching
  • Public services run on an isolated Docker network: they can reach neither the local network, nor the VPN, nor other containers
  • Administration only goes through a Tailscale VPN, and SSH only accepts key-based logins

Tools in place

System
Ubuntu Server LTS, automatic security updates
Containers
Docker and Docker Compose, one stack per application
Hardening
Non-root, read-only containers without privileges; UFW firewall
Administration
Portainer for containers, Cockpit for the system
Monitoring
Uptime Kuma for probes and alerts, Healthchecks.io to be warned if the server goes down
Private configuration
Personal project · 2026

OrthoAutoAI

A spelling and grammar corrector for Windows that works in any application: select the text, press Alt + C, and it is replaced with its corrected version.

What it does

  • AI-powered correction: text is corrected by Google's Gemini 2.5 Flash model, which takes context into account
  • Everywhere: Notepad, Word, Discord, browsers…
  • Optional confirmation to review the correction before applying it
  • History of the last 5 corrections
  • 7 interface languages: French, English, Spanish, German, Italian, Portuguese and Romanian
  • Settings: custom shortcuts, confirmation sound, launch at startup, system tray icon

How it's built

Language
AutoHotkey v2, compiled into a Windows executable
How it works
The selected text goes through the clipboard, is sent to the Gemini API in an HTTP request, then the answer is pasted in its place
AI
Google's Gemini API: each user brings their own free key
Website
Landing page in 7 languages, with light and dark themes

Community

The project was picked up by kiliotsu, who made a Linux port of it: a rewrite in Python and GTK4 that supports Wayland (including Hyprland) and X11, with an install script and no external Python dependencies. The fork keeps the same features and credits the original project.

Personal project · 2026

D-Wallet

A personal spending tracker. I import my bank statement, transactions sort themselves into categories, and I follow my spending month by month on a dashboard.

What it does

  • Bank statement import in CSV format, with a preview to approve before saving
  • Rules engine: a keyword in the label sets a category, applied automatically on every import
  • Dashboard and totals by category and by month
  • Ledger of every transaction, editable by hand
  • Import history, with the option to undo a whole import
  • Excel export of transactions

How it's built

Backend
Python API with Flask, SQLite database, pandas to read statements and produce the Excel export
Frontend
Vue 3 with Vue Router, Vite and Tailwind CSS 4
Startup
A script starts the API and the interface, then opens the browser; the interface proxies its calls to the API

A Mole in the Hole

A board game in Python, built by a team of four for the end-of-first-year project (1PROJ). Players move their moles into the holes of several boards in a row; whoever takes the very last hole wins.

The game

  • 2 to 4 players, on the same computer or over a local network, or solo against an AI with two levels
  • Two modes: classic (4 boards) and custom (3 to 6 boards, randomly placed squares)
  • 4 visual themes, each with its own music and sound effects
  • 5 languages: French, English, Spanish, Italian and German

My part

  • The graphical interface: launcher, profile and settings pages, board display, game setup and the on-screen game loop
  • Wiring into the interface the AI, turn skipping, quick start and cheat mode
  • Per-theme visuals (pawns, bonus squares, holes, barriers) and the end-of-game screen

How it's built

Language
Python, with game logic, interface, sound and networking kept separate
Interface
Tkinter, with Pillow for images
Sound
miniaudio for music and sound effects
Team
4 students, working with branches and pull requests on GitHub
